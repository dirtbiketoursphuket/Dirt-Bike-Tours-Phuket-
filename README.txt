HOW TO PUT THIS WEBSITE ONLINE (GitHub Pages)

1. Create a free GitHub account at https://github.com if you don't have one.

2. Create a new repository:
   - Click the + button (top right) → New repository
   - Name it something like: Dirt-Bike-Tours-Phuket
   - Make it Public
   - Do NOT add a README or any files
   - Click "Create repository"

3. Upload the files:
   - Click "uploading an existing file"
   - Drag and drop the index.html file (and this README if you want)
   - Click "Commit changes"

4. Turn on GitHub Pages:
   - Go to Settings → Pages (left menu)
   - Under "Source" choose "Deploy from a branch"
   - Select branch: main
   - Folder: / (root)
   - Click Save

5. Wait 1–2 minutes, then open the link GitHub gives you.
   It will look like: https://yourusername.github.io/Dirt-Bike-Tours-Phuket/

That's it. Your website is live.
