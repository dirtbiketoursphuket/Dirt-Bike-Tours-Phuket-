# Dirt Bike Tours Phuket Website

## Files
- index.html — complete website
- style.css — design and responsive layout
- script.js — mobile menu, year, WhatsApp booking form
- logo.png — generated Dirt Bike Tours Phuket logo

## IMPORTANT BEFORE PUBLISHING
Open `script.js` and change:
    const WHATSAPP_NUMBER='66900000000';
to your real WhatsApp number in international format, digits only.

Also change the `tel:+66900000000` link in `index.html`.

## Free hosting with GitHub Pages
1. Create a free GitHub account at github.com.
2. Create a new public repository, e.g. `dirt-bike-tours-phuket`.
3. Upload all four files.
4. Go to Settings → Pages.
5. Select Deploy from branch → main → /(root).
6. Save. GitHub will give you a free `github.io` website address.

## Custom domain
Later you can buy a domain such as dirtbiketoursphuket.com and connect it to GitHub Pages.

## Replace placeholders
The site currently uses graphic placeholders for the bike/tour photography. Replace them with your own CRF and Phuket photos if desired.
